WatchOptions

PropertyTypeDescription
timeout?numberBatch coalescing window (ms). Default ~20 ms; not the port's read timeout.
size?numberMax bytes per read chunk; a batch is also flushed once this many bytes are buffered.
serialDataFlushIntervalMs?numberBatch flush interval (ms); takes precedence over timeout. All platforms.
decode?booleanDefault true — stream-decode with TextDecoder.
routeUrc?booleanWhen true, native hub line-routes idle RX so AT URC lines become onUrc events (and are removed from onData). Default: true if onUrc is provided, else false (raw byte stream — required for binary / NMEA). Ignored on CMUX channels (openMuxChannel()), as is size.
parser?ParserOptionsFrame RX natively (Node @serialport/parser-* semantics): each complete frame becomes exactly one onData call and the batch window (timeout, serialDataFlushIntervalMs) no longer applies. With decode (default) each frame is decoded on its own. An invalid config rejects watch() before the watch starts. With routeUrc / onUrc, URC lines are split off first and only the other lines reach the parser. On unwatch(), close() or a disconnect, the parser's buffered partial frame is delivered as a last onData call (before onDisconnect). Auto-reconnect restores the watch with the same parser.

ParserOptions

Native parser selection for watch({ parser }). maxBufferSize (default 65536) caps bytes buffered without a complete frame; see each variant for what happens at the cap. Unknown keys make watch fail (a typo would otherwise fall back to a default).

export type ParserOptions =
  /** Split on a byte sequence (`@serialport/parser-delimiter`). Full buffer is emitted as a frame. */
  | { type: 'delimiter'; delimiter: ByteSeq; includeDelimiter?: boolean; maxBufferSize?: number }
  /** Split on `delimiter`, default `"\n"` (`@serialport/parser-readline`). */
  | {
      type: 'readline';
      delimiter?: ByteSeq;
      includeDelimiter?: boolean;
      maxBufferSize?: number;
      /** Node's string-rendering option: accepted and ignored (frames are decoded by `watch`). */
      encoding?: string;
    }
  /** Fixed-size frames of `length` bytes (`@serialport/parser-byte-length`). */
  | { type: 'byteLength'; length: number }
  /**
   * A frame ends after `intervalMs` (alias `interval`) of silence (`@serialport/parser-inter-byte-timeout`).
   * Give exactly one of `intervalMs` / `interval`.
   */
  | { type: 'interByteTimeout'; intervalMs: number; interval?: never; maxBufferSize?: number }
  | { type: 'interByteTimeout'; interval: number; intervalMs?: never; maxBufferSize?: number }
  /**
   * Delimiter + little-endian length field (`@serialport/parser-packet-length`).
   * Defaults: delimiter 0xaa, delimiterBytes 1, packetOverhead 2, lengthBytes 1,
   * lengthOffset 1, maxLen 0xff, maxBufferSize 65536 (a packet that cannot complete
   * within it is emitted as a frame).
   */
  | {
      type: 'packetLength';
      delimiter?: number | number[];
      delimiterBytes?: number;
      packetOverhead?: number;
      lengthBytes?: number;
      lengthOffset?: number;
      maxLen?: number;
      maxBufferSize?: number;
    }
  /** Drop everything until `delimiter`, then pass data through (`@serialport/parser-ready`). */
  | { type: 'ready'; delimiter: ByteSeq }
  /** Split UTF-8 text on a regular expression (Rust `regex-lite` syntax, not a JS `RegExp`). */
  | {
      type: 'regex';
      regex: string;
      maxBufferSize?: number;
      /** Node's string-rendering option: accepted and ignored. */
      encoding?: string;
    }
  /** Frames between a start and an end marker (`@serialport/parser-start-end`). */
  | {
      type: 'startEnd';
      startDelimiter: ByteSeq;
      endDelimiter: ByteSeq;
      includeStartDelimiter?: boolean;
      includeEndDelimiter?: boolean;
      maxBufferSize?: number;
    }
  /** SLIP (RFC 1055) decoder (`@serialport/parser-slip-encoder` `SlipDecoder`); bytes default to RFC values. */
  | {
      type: 'slip';
      start?: number;
      esc?: number;
      end?: number;
      escStart?: number;
      escEnd?: number;
      escEsc?: number;
    }
  /** ccTalk frames, length in byte 1 (`@serialport/parser-cctalk`). A partial frame is dropped after `maxDelayMs` (default 50, 0 = never). */
  | { type: 'ccTalk'; maxDelayMs?: number };
