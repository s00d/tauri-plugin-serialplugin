API reference

Tauri commands

Every Tauri command of the plugin with its arguments, generated from src/commands.rs.

The #[tauri::command] functions in src/commands.rs, which the JS package calls with invoke('plugin:serialplugin|<name>', args). You normally use the SerialPort class instead; this list is for calling commands directly or from Rust (see Rust). Arguments are sent in camelCase; AppHandle and State parameters are injected by Tauri and not listed.
