---
title: "Permissions"
description: "Capability identifiers for the plugin commands."
---

`serialplugin:default` allows every command of the plugin; that is what most apps want:

```jsonc
"permissions": ["core:default", "serialplugin:default"]
```

For a narrower capability, list the `allow-*` identifiers you need instead (and
`deny-*` to take one away from a broader set). Every command has a pair, named
after the command with `_` replaced by `-`
(`available_ports` → `serialplugin:allow-available-ports` / `serialplugin:deny-available-ports`).

The full list of identifiers, with descriptions and the contents of
`serialplugin:default`, is in the [permissions reference](/reference/permissions),
generated from `permissions/` in the repository.
